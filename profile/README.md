# TransitionZero

TransitionZero is a climate tech non-profit founded in 2021. We develop software to reduce the time to build clean energy at scale.

## TZ-OSeMOSYS

`pip install tz-osemosys`

Our rebuilt, tested implementation of OSeMOSYS for long-term capacity expansion. Define a model in YAML or Python, solve it with HiGHS, CBC, Gurobi or CPLEX, and inspect every equation. Backwards-compatible with existing OSeMOSYS and otoole workflows. See the [repo](https://github.com/transition-zero/tz-osemosys) and [docs](https://docs.transitionzero.org).

## Scenario Builder

Our flagship tool, [Scenario Builder](https://builder.transitionzero.org), lets policymakers, planners and investors build, analyse and share power system models in the browser: capacity expansion and hourly dispatch in a single workflow, solved in the cloud.

It runs on TZ-OSeMOSYS for long-term capacity expansion and the community-built [PyPSA](https://github.com/pypsa/pypsa) for hourly dispatch. AMP, the AI modelling agent built into the platform, helps build scenarios, debug infeasible runs and analyse results in plain language. All of it is supported by model-ready data for 17 countries, solutions engineering and [market insights](https://www.transitionzero.org/insights).
